What We Changed in Bootstrap

All Bootstrap color classes (.bg-primary, .text-primary, .btn-primary, .border-primary, etc.) are overridden to use TWMC brand colors. This applies everywhere Bootstrap uses colors — buttons, backgrounds, text, borders, badges, alerts. GROW pathway colors are not mapped to Bootstrap — they are reserved for pathway pages only.

Timing Tokens

All transitions use CSS custom property duration tokens. Never hardcode transition durations.

--duration-fast
0.15s — links, icons
--duration-normal
0.3s — buttons, states
--duration-slow
0.5s — cards, panels
CSS
--duration-fast: 0.15s;   /* links, icons, micro-interactions */
--duration-normal: 0.3s;  /* buttons, nav items, state changes */
--duration-slow: 0.5s;   /* cards, panels, FAQ accordion */

/* Usage */
.my-element {
  transition: all var(--duration-normal) var(--ease-out);
}

Animations

Scroll-triggered reveal animations bring content to life as visitors scroll. Uses IntersectionObserver with auto-stagger for batched reveals.

fadeUp
+ delay
+ more delay

Click any box to replay the animation

HTML + JS
<!-- Add .reveal to any element -->
<div class="reveal">Content fades up on scroll</div>

/* CSS */
.reveal {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity 0.7s var(--ease-out),
               transform 0.7s var(--ease-out);
}
.reveal.visible {
  opacity: 1;
  transform: translateY(0);
}

// JS (in theme.js)
const observer = new IntersectionObserver((entries) => {
  entries.forEach(e => {
    if (e.isIntersecting) e.target.classList.add('visible');
  });
}, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
